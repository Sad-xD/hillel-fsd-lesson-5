# Персональний сайт-візитка

## Мета проєкту
Створення персонального вебсайту для представлення
інформації про себе, освіту, професійні навички
та досягнення.

## Використані технології
- HTML5 — створення структури вебсторінки.
- CSS3 — оформлення та адаптивний дизайн.

## Перевірка результату

Після публікації сайту на GitHub Pages було перевірено:
- Доступність сайту за публічним посиланням.
- Коректність відображення HTML-елементів.
- Підключення CSS-стилів.
- Відображення зображень.
- Працездатність посилань.

Результат: сайт успішно відкривається у браузері,
стилі та зображення завантажуються коректно,
посилання працюють.
